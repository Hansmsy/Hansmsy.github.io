UniNote 最值得参考的地方，是把笔记内部已有的结构转化为训练信号：图片与描述对应，图片属于某篇笔记，不同子笔记之间具有可控制的内容重合度。这些关系分别支持跨模态对齐、局部与整体匹配，以及笔记之间的相关性排序。本文依据论文 v2，聚焦数据构造和两阶段训练；示例用于解释方法，文末单独讨论我对优化目标的疑问。

01两阶段分别学习什么

一篇笔记通常同时包含标题、正文、多张图片和图片中的文字。把它压缩成一个向量后，既要保留整体主题，也要支持用其中一张图片或一段文字找回整篇笔记。进一步地，检索出多篇相关笔记以后，还希望向量相似度能够反映相关程度，而不只是区分“相关”和“不相关”。

训练阶段希望获得的能力主要监督来源
第一阶段：Contrastive SFT跨模态对齐，以及局部内容与整篇笔记的双向匹配图文对应、OCR、笔记内部从属关系与困难负样本
第二阶段：Relative Reranking让笔记之间的相似度进一步体现内容相关性的层次通过拆分与逐步补充内容构造的排序标签

例如，一张咖啡机图片应能找到包含相关内容的整篇选购笔记；当候选中既有同款机器的详细介绍，也有泛泛的咖啡制作记录时，还需要区分它们的相关程度。这只是应用示例，论文第二阶段具体使用的是内容重合度构造监督，不能直接等同于完整的用户兴趣或推荐价值。

这里的“两阶段”指训练流程。推理时仍然分别编码查询和候选，再用向量相似度检索、排序；候选向量可以提前计算并建立索引。第二阶段没有额外接入一个逐对读取查询与候选、生成判断的重排大模型。

02从原始笔记构造训练素材

论文附录 A 给出的起点是：从小红书原始数据中筛选点赞数大于 100的笔记，并按主题和每篇笔记的图片数量做均衡处理。点赞门槛用于初步筛选素材，本身不是任意两个内容之间的相关性标签，也不意味着筛出的每篇笔记都具备严格验证过的内容质量。

对每张图片，再补充两类文本信息：

  • 图片描述：用 Qwen3VL-8B-Instruct 生成 caption，表达图中的对象、场景等语义信息。
  • 图片文字：用专门的 OCR 模型提取图中文字。OCR 负责识别文字，caption 负责描述图像，两者提供不同的匹配线索。

为方便后面的例子，记一篇笔记为 N = {标题、正文、I₁、I₂、…、OCR₁、OCR₂、…}，图片 Iᵢ 的描述记为 Cᵢ。论文中的视频也按图像序列处理。标题与正文来自原始笔记，caption 和 OCR 是补充的信息。

文中涉及的模型有三种职责，需要分清：

职责论文配置输出或用途
生成训练素材Qwen3VL-8B-Instruct 与 OCR 模型图片描述和图中文字
挖掘困难负样本Qwen3VL-8B-Embedding参考向量与相似度
实际训练的 UniNote以 Qwen3VL-8B-Instruct 为底座，进行 LoRA 微调统一的多模态 embedding

第一阶段由此构造了 90 万条样本，覆盖除 Note2Note 以外的九种检索方向，每种 10 万条；第二阶段另行构造 6 万条笔记排序样本。模型配置见原文第 4.1 节，数据细节见附录 A、B。

03第一阶段：正例与模态替换

从笔记自身关系得到正例

第一阶段的监督可以从同一篇笔记内部获得，不必先为大量任意笔记对逐一标注相关性。图片与它的描述对应，图片和描述属于原笔记，OCR 又来自某张图片。论文将这些关系组织成四类任务：

任务检索方向正例依据
原子级对齐图片 ↔ 图片描述Cᵢ 是对 Iᵢ 的描述
局部检索整体图片／描述 → 笔记局部内容来自该笔记
整体检索局部笔记 → 图片／描述笔记包含相应内容
OCR 感知图片 ↔ OCR；OCR → 笔记图中文字的来源与从属关系

双向任务拆开计数后共有九个方向。它们既是训练组织方式，也对应实际检索能力；Note2Note 并不是唯一有用的最终任务。

为什么还要做模态替换

如果查询是一张图片 Iᵢ，正例笔记中又原封不动地包含 Iᵢ，模型可能依赖重复图片的局部特征完成匹配。这样获得的训练信号，未必足以要求模型理解“这张图表达的内容与整篇笔记有什么关系”。

论文为此引入 Modal Replacement：保留查询图片，从正例笔记中移除这张图片，再放入它的文字描述。

\[q=I_i,\qquad N'=(N\setminus\{I_i\})\cup\{C_i\},\qquad (q,N')\text{ 为正例。}\]

举例说，查询是“咖啡机正面图”，原笔记包括机器图片、配件图片和选购正文。构造正例时，把机器图片替换成“银色半自动咖啡机，正面有压力表”等描述，其余内容保留。查询侧是视觉信息，候选侧通过文字保留对应语义，训练就需要建立跨模态匹配。

原文还给出了 (Cᵢ, N) 这种文字查询形式。这里值得借鉴的是保留目标语义，同时削弱直接复制带来的匹配捷径。原文明确展示的是上述图片与描述的替换，不应将其扩展成所有模态之间任意置换的完整实现。

04困难负样本与软标签

全局挖掘：挑选相似但需要区分的候选

随机负例可能与查询相差太远，例如用咖啡机图片匹配完全无关的风景笔记。模型较容易区分这类内容，却未必能区分外观接近的机器或主题相近的笔记。

UniNote 使用参考编码器 φ 对查询和候选池编码，保留相似度落在指定区间的困难负样本：

\[0.5\leq\cos\bigl(\phi(q),\phi(c^-)\bigr)\leq0.7.\]

0.5–0.7 是余弦相似度区间，由作者通过人工抽样检查确定。其意图是避开过于容易的负例，同时减少把高度相关内容当成负例的风险。这是针对论文数据和参考模型选择的阈值；更换编码器或数据后，相似度分布会变化，不能机械照搬，也不能依靠这个区间保证没有假负例。

局部 MaxSim：修正复合笔记的监督分数

一篇笔记包含多张图和多段文字，整体向量可能掩盖某个局部的高度相关性。例如，一篇“厨房布置”笔记整体主题较宽，但其中恰好有一张与查询很接近的咖啡机图片。

对这类复合候选，论文用查询与候选各组成部分的最大相似度形成更细的软监督：

\[s'(q,c^-)=\max_{e\in c^-}\operatorname{sim}(q,e).\]

它保留“这个候选的某个局部其实很接近查询”的信息，再用于训练中的分布对齐。这里的 MaxSim 是构造监督分数的步骤，不意味着部署时必须把每篇笔记存成一组局部向量并逐一比较。

规则构造：从正例上下文中删除查询对应的内容

另一类困难负例直接来自原笔记：查询仍然是 Iᵢ，候选改成删除 Iᵢ 后的笔记。

\[(q,c^-_{\mathrm{rule}})=\bigl(I_i,N\setminus\{I_i\}\bigr).\]

这与前面的模态替换只有一个关键差别：删除图片后，不再补回它的描述。两种操作放在一起，才容易看清训练意图：

查询候选构造论文中的标签
图片 Iᵢ原笔记删除 Iᵢ，再加入对应描述 Cᵢ正例：换一种模态保留目标信息
图片 Iᵢ原笔记仅删除 Iᵢ规则负例：移除直接的从属关系

这种构造保留了大量共同背景，要求模型关注目标信息是否存在。我的理解是，它适合训练细粒度的成员匹配，但需要注意语义冗余：即使删掉图片，正文、OCR 或其他图片仍可能表达同一内容。删除成员不必然使剩余笔记在语义上不相关。如果将这套方法迁移到业务中，我会额外检查这种假负例，而不直接把结构关系当作绝对语义标签。

05把生成模型训练成嵌入模型

样本准备好后，查询、正例和负例分别输入同一个多模态模型。模型取最后一个 token 的隐藏状态作为表示，再计算查询与各候选的余弦相似度。训练调整的是表示空间；caption 生成发生在准备数据时，不能把这里的 Contrastive SFT 理解成让模型逐 token 生成检索答案。

对于同一候选集合 Ω，参考分数 s 经过 softmax 得到目标分布 Q，待训练模型的向量相似度经过 softmax 得到预测分布 P：

\[Q(c_i\mid q)=\frac{\exp(s_{q,c_i}/\tau)}{\sum_{c_j\in\Omega}\exp(s_{q,c_j}/\tau)},\qquad P(c_i\mid q)=\frac{\exp(\cos(e_q,e_{c_i})/\tau)}{\sum_{c_j\in\Omega}\exp(\cos(e_q,e_{c_j})/\tau)}.\]

随后最小化两个分布的差异。这样，模型除了学习正负关系，还能保留候选之间的软相关性差异。图中的 MRL 则在多个嵌套维度上施加相同类型的训练目标，使向量截短后也受到监督；它服务于表示维度的选择，不改变前面的样本构造逻辑。

原文公式中一个需要留意的细节

论文式（8）将目标称为 JS 散度，但写出的表达式是 ½ KL(P‖Q) + ½ KL(Q‖P)，即对称 KL 的一半。标准 JS 应引入混合分布 M = (P + Q) / 2，计算 ½ KL(P‖M) + ½ KL(Q‖M)。因此，理解方法时可以先把这一目标视为分布对齐；具体复现时需要核对实际实现，不能仅依据名称认定用了标准 JS。

06第二阶段：构造相关性排序

第一阶段已经训练了多种匹配关系。第二阶段进一步把监督细化为：对同一个查询，哪些相关笔记应该排在更前面？论文通过人为控制内容重合度获得顺序，不依赖逐对人工排序，也不直接拿点赞量作为相关性标签。

  1. 把一篇笔记的视觉和文字组成部分拆分成两个等份子笔记 NA、NB，两者的组成部分不重叠，合起来恢复原笔记。
  2. 令查询 q = NA，以 NB 为候选的起点。
  3. 逐步把 NA 中的内容加入 NB，生成与查询具有不同重合程度的候选。原文公式用逐个加入图像成员展示这个过程。
  4. 把加入内容更多的候选排在前面，再混入其他无关笔记作为噪声候选。

下面用三个查询成员 A₁、A₂、A₃ 示意这一过程，B 表示另半篇笔记。表中顺序就是按该规则生成的监督顺序：

查询候选内容监督顺序
q = {A₁, A₂, A₃}B + A₁ + A₂ + A₃最靠前
B + A₁ + A₂其次
B + A₁再次
B仍属相关集合，排在上述候选之后
其他无关笔记排在相关候选之后

这里有两个容易忽略的边界。首先，拆分后没有共享成员，不代表两个子笔记的语义完全无关；原文仍把 B 纳入相关集合。其次，内容重合度是这个训练设置中定义的相关性代理：它能提供可控制的排序梯度，但真实检索中的信息价值、事实一致性和用户需求，并不总随重复内容数量单调增加。

我认为这部分最可迁移的思路，是通过控制一个因素的变化构造顺序监督。不必让模型凭空判断任意两篇笔记的精确相关分，而是从同一来源出发，逐步增加目标内容，使训练样本之间具有可解释的差异。

07排序奖励与组内优势

模型先按向量相似度检索并排序，取 Top-G 候选组成一组。论文设定 G 大于相关候选数量 M，使这一组同时能够反映相关内容的召回和噪声混入情况。然后对组内每个候选分别计算奖励。

奖励项计算意图
无关内容惩罚如果无关笔记排在任何相关笔记之前，就给予负奖励；越靠前惩罚越重。若它位于所有已检索相关笔记之后，则该项为零。
相关内容基础奖励相关候选获得固定基础奖励，优先鼓励找到相关内容。
绝对位置奖励候选的预测位置越接近标签位置，奖励越高。
相对顺序奖励比较它与其他相关候选的前后关系，正确的成对顺序越多，奖励越高。

这个设计把“相关内容是否被找到”和“找到后顺序是否正确”区分开来。单看位置距离，会遗漏候选之间的相对关系；单看成对顺序，又不能完整表达无关内容占据前排的代价。

得到每个候选的奖励 rᵢ 后，再在当前查询的候选组内标准化：

\[A_i=\frac{r_i-\operatorname{mean}(r)}{\operatorname{std}(r)+\epsilon}.\]

论文接着用优势加权的策略对数概率项和 KL 约束更新模型，并将该过程称为 GRPO。其意图是增加高优势候选的策略概率，同时通过参考策略约束更新幅度。但向量相似度如何具体定义成策略概率，是阅读和复现时需要进一步明确的环节。

与常见语言模型 GRPO 相比，关键差异是：这里的一组是检索出的 G 个候选笔记，奖励分配到候选；常见设置是在同一问题下采样 G 条回答，再比较回答的奖励。也不能把它理解成采样 G 份完整排序列表。训练候选来自构造的数据，Top-G 的成员及其顺序则可能随模型更新而变化，不能笼统说成始终固定不变。

08我的思考：为什么使用 GRPO

我认可这篇论文的数据构造：先用跨模态和局部整体关系学习表示，再用可控制的内容变化学习相关性层次。但对于第二阶段的优化方法，我仍有一个疑问：既然已经构造出明确的排序标签，为什么选择 GRPO，而不是直接使用排序损失？

已有顺序，可以先直接监督相似度差异

若候选 cw 应排在 cl 前，可以直接要求前者的相似度更大。例如，一个简单的 pairwise 目标是：

\[\mathcal{L}_{\mathrm{pair}}=-\log\sigma\left(\frac{s_\theta(q,c_w)-s_\theta(q,c_l)}{\tau}\right).\]

也可以用 listwise 目标监督整组候选的顺序。这些方法能够通过相似度直接反向传播，不需要对离散排序操作本身求导。它们同样可以训练一个统一的 embedding 模型，因此，“减少独立 reranker”本身并不是选择 GRPO 的充分理由。

DPO 是可以讨论的方向，但不等于普通成对排序

我最初想到的是：既然有更相关和更不相关的候选，能否用 DPO？关键在于，DPO 使用的是当前策略相对于参考策略的偏好概率关系，不能直接把任意两个余弦分数相减就称为 DPO。

若迁移到检索，可以考虑先在明确的候选集合上，通过相似度 softmax 定义候选选择概率，再引入参考策略构造偏好目标。这属于需要补充定义的改造方案，并不是 UniNote 已经给出的做法。对于这篇论文现成的排序标签，我会首先把直接 pairwise／listwise 训练作为比较起点，再判断是否需要额外的策略优化框架。

组内奖励解释了动机，策略定义仍需要交代

作者给出的理由是：排序天然包含一组候选，适合通过组内相对奖励进行优化。我的理解是，如果希望直接组合召回、前排噪声惩罚和顺序一致性等离散目标，奖励优化具有合理动机。不过，存在一组候选并进行奖励标准化，还不足以完整说明 GRPO 的实现。

参照 DeepSeekMath 中的 GRPO，我希望进一步明确以下问题：

  • 动作和概率是什么？模型选择一个候选、生成一个排列，还是对连续相似度建模？原文式（13）写作相似度的策略概率，但没有明确其分布形式和归一化范围。
  • 检索如何对应策略采样？Top-G 检索被用于模拟组采样，但确定性的相似度截断与从策略分布采样并不相同；需要解释训练数据与策略梯度之间的对应关系。
  • 更新目标如何实现？式（13）呈现了优势加权 log-prob 与 KL 项，没有显式给出常见 GRPO 的新旧策略概率比和 clipping。实际实现是否包含这些机制，以及目标采用最大化还是负号转成最小化损失，都需要核对。
  • 收益具体来自哪里？可控的排序数据、层次奖励和优化算法都会影响学习。若要论证使用 GRPO 的必要性，需要在相同数据与编码器条件下，与直接排序损失进行比较。

这些疑问不等于否定奖励优化，也不意味着排序任务只能使用 DPO。对我而言，UniNote 最值得吸收的是利用内容结构生成匹配监督，再利用可控制的内容差异生成排序监督。这套数据设计与采用哪一种优化算法可以分别讨论；至于 GRPO 的必要性，我希望看到更明确的策略定义和实现说明。
